# Permata POS — Frontend (GitHub Pages)

Frontend statis (HTML/CSS/JS vanilla) untuk POS & Operasional Toko Emas & Perak Permata.
Backend: Google Apps Script (REST API JSON) — dikirim terpisah sebagai `Kode.gs`.

```
index.html          <- harus di root repository
css/style.css
js/config.js        <- ISI GAS_URL di sini sebelum push
js/api.js           <- klien fetch ke Apps Script
js/app.js           <- seluruh logika aplikasi
```

Panduan lengkap: lihat `PANDUAN-INSTALASI.md`.
